1. ข้อมูลทั่วไป
ระบบ Customer Activity Monitoring (CAM) ใช้ติดตามธุรกรรมของลูกค้าเพื่อรายงานต่อฝ่าย Compliance ข้อมูลทั้งหมดในเอกสารนี้เป็นข้อมูลสมมติ (Synthetic)
2. Rule 3 ธุรกรรมมูลค่าสูง
- ระบบต้องแสดงรายการลูกค้าที่มียอดรวมธุรกรรมมากกว่าหรือเท่ากับ 200,000 บาท ย้อนหลัง 30 วัน ในรายงาน High Value Alert
- ระบบต้องไม่นำรายการกองทุน PVD มารวมในการคำนวณยอดรวมธุรกรรมของรายงาน High Value Alert
- เจ้าหน้าที่Compliance ต้องสามารถ Export รายงาน High Value Alert เป็นไฟล์ CSV
3. Rule 4 Transaction Monthly Report (ปรับปรุง)
- ระบบต้องแสดงรายการลูกค้าที่มียอดรวมธุรกรรมมากกว่า 200,000 บาท ย้อนหลัง 14 วัน ในรายงาน High Value Alert
- ระบบต้องคำนวณยอดรวมรายเดือนของลูกค้าแต่ละราย และแสดงใน Customer Transaction Monthly Report
- ระบบต้องประมวลผลรายงานอย่างรวดเร็วและเหมาะสม
4. Rule 5 Validation หน้าจอค้นหาลูกค้า
- ฟิลด์ Customer ID เป็นฟิลด์บังคับ ระบบต้องแสดงข้อความ "กรุณาระบุ Customer ID" เมื่อผู้ใช้ไม่กรอก หากค่าว่างให้แสดงข้อความเดียวกัน
- เจ้าหน้าที่Compliance ต้องกรอกหมายเหตุได้ความยาวไม่เกิน 200 ตัวอักษร และระบบต้องแสดงข้อความ "หมายเหตุยาวเกินกำหนด" เมื่อเกิน หากค่าว่างให้บันทึกได้
5. Rule 6 Customer API
- เมื่อเรียก API GET /customers/{id}/transactions ด้วย Customer ID ที่มีอยู่ ระบบต้องตอบกลับ HTTP 200 พร้อมรายการธุรกรรมในรูปแบบ JSON ให้เจ้าหน้าที่Compliance
